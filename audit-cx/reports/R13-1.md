### F-CX-R13-1-1 -- Selected chip toggle uses transparent fill instead of opaque
**Severity:** S1
**Where:** apps/mobile/src/domains/setup/components/ManageHouseholdScreen.tsx:581
**Evidence:** `                        ? 'border-primary bg-primary/10 text-primary'`
**Rule:** 00-FOUNDATIONS.md §8.4, Chip selection is weight + fill together (`bg-primary` + `text-primary-foreground` and `fontWeight: 600`), never fill alone or an alpha fill.
**What the user sees:** The selected week start option uses a faint transparent plum fill, which looks inconsistent with standard chip toggles.
**Fix:** Update the selected class string to use `bg-primary text-primary-foreground font-semibold` in the component.
