### F-CX-R16-3-1 -- Input uses text below the 16px minimum for body copy
**Severity:** S1
**Where:** apps/mobile/src/components/ui/input.tsx:31
**Evidence:** `        'web:flex h-10 native:h-12 web:w-full rounded-lg border bg-card px-3 web:py-2 text-base lg:text-sm native:text-lg native:leading-[1.25] text-foreground placeholder:text-muted-foreground web:ring-offset-background file:border-0 file:bg-transparent file:font-medium web:focus-visible:outline-none web:focus-visible:ring-2 web:focus-visible:ring-ring web:focus-visible:ring-offset-2',`
**Rule:** 00-FOUNDATIONS.md § 1, Typography minimum is 16px for body text.
**What the user sees:** Input text on large screens renders at 14px, which is too small and breaks the typography floor.
**Fix:** Remove `lg:text-sm` from the Input component's class list so it defaults to at least `text-base` (16px).

### F-CX-R16-3-2 -- ReceiptCard combines a green status tint with a green category chip
**Severity:** S1
**Where:** apps/mobile/src/components/ui/receipt-card.tsx:37
**Evidence:** `        <IconChip tone="hours" icon={CircleCheck} />`
**Rule:** 00-FOUNDATIONS.md § 3.3, a card may never show both a status tint and a category chip in the same colour family.
**What the user sees:** A green positive confirmation card containing a green sage category chip, blurring the line between a status message and a category label.
**Fix:** Change the `tone` of the `IconChip` to `brand` or remove the category chip entirely.

### F-CX-R16-3-3 -- BackButton uses an arbitrary gap off the 8pt grid
**Severity:** S3
**Where:** apps/mobile/src/components/ui/back-button.tsx:30
**Evidence:** `      className="-ml-2 h-11 flex-row items-center gap-0.5 self-start pl-2 pr-3"`
**Rule:** 00-FOUNDATIONS.md § 1, Spacing is an 8pt grid and must not use arbitrary values.
**What the user sees:** The gap between the back chevron and the label is slightly off-grid, breaking the rhythm of the layout.
**Fix:** Change `gap-0.5` to `gap-1` (4px) or `gap-2` (8px) in the BackButton class list.
