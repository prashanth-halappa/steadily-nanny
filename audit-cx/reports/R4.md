### F-CX-R4-1 -- Carer chip selection lacks weight shift
**Severity:** S1
**Where:** apps/mobile/src/domains/schedule/components/ExtraShiftScreen.tsx:299
**Evidence:** `                    selected ? 'text-primary-foreground' : 'text-foreground'`
**Rule:** 00-FOUNDATIONS.md §8.4, selection requires weight + fill together, never fill alone.
**What the user sees:** The selected carer chip changes colour but stays the same font weight, relying on colour alone for state.
**Fix:** Add `font-semibold` to the selected state's Text className in ExtraShiftScreen.

### F-CX-R4-2 -- Decline button uses ghost variant
**Severity:** S1
**Where:** apps/mobile/src/domains/schedule/components/ScheduleRespondScreen.tsx:365
**Evidence:** `          variant="ghost"`
**Rule:** 01-LAWS.md §G, ghost is for optional/reversible/"not now" actions, while secondary/outline is for an equally valid second answer. Decline is a definitive answer.
**What the user sees:** The Decline option looks like a dismissable or optional action rather than a formal response to the proposed schedule.
**Fix:** Change the Decline button's variant to `outline` in ScheduleRespondScreen.
