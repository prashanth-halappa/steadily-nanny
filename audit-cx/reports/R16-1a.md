### F-CX-R16-1a-1 -- Button uses opacity dimming for disabled loading state
**Severity:** S1
**Where:** apps/mobile/src/components/ui/loading-button.tsx:203
**Evidence:** `        isLoading ? { opacity: 0.8 } : undefined,`
**Rule:** 00-FOUNDATIONS.md §8.3, Disabled state must use `disabled:bg-muted` and `disabled:opacity-100`, never a flat opacity dim, because dimming a filled plum button makes it read as a plausible enabled lavender secondary button rather than disabled.
**What the user sees:** When the button enters its loading state, it dims to 80% opacity, making it visually read as an active, clickable secondary action instead of an inactive loading surface.
**Fix:** Remove the inline opacity override in apps/mobile/src/components/ui/loading-button.tsx so the button falls back to its correct semantic disabled style.
