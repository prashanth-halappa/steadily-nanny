### F-CX-R16-1b-1 -- Decorative icon wrapper uses a circle instead of a rounded square
**Severity:** S1
**Where:** apps/mobile/src/components/ui/empty-state.tsx:41
**Evidence:** `      'w-24 h-24 rounded-full bg-muted items-center justify-center mb-4',`
**Rule:** 00-FOUNDATIONS.md Section 1, which states that decorative icons must use a rounded square (like `rounded-cell`), never a circle (`rounded-full`), to avoid being confused with an avatar.
**What the user sees:** A decorative icon sits in a circular container, reading as a person's avatar in an interface that reserves circles for real people.
**Fix:** Change `rounded-full` to a soft radius token like `rounded-cell` in `VARIANT_STYLES.default` in apps/mobile/src/components/ui/empty-state.tsx.
